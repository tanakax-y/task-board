# TaskBoard

Inbox とカンバンボード、行動ログをまとめた、シンプルなタスク管理アプリです。

## タスク
- 思いついたことを Inbox にすばやく追加（作成日時つき）
- チェックで処理済（取り消し線）、もう一度で未済に戻す
- 一覧表示 / カレンダーで日別に絞り込み
- カンバンボード（列の追加・並べ替え、ドラッグ＆ドロップ）

## ログ
- ⏱ 時間：仕事・勉強・睡眠などをタップで記録（別のアクションをタップすると自動で切り替え）。付け忘れは「あとから記録」で追加
- 📅 デイリー：起床・電車などピンポイントの時刻や数値を記録し、グラフ・一覧で推移を確認
- ✅ 習慣：筋トレ・ウォーキングなどを週ごとにチェック（週◯回の目標つき）
- 📊 レポート：日・週・月ごとの時間の内訳（未記録の時間も表示）、CSV 書き出し

iPhone / PC 間でリアルタイム同期（Supabase）。ビルド不要の単一 `index.html` です。ローカルでは `server.ps1` で配信できます。
